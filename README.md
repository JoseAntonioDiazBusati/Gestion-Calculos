# Calculadora en POO

- El proyecto es una calculadora que guarda los resultados de las operaciones en un archivo `.txt` dentro de una carpeta denominada logs.

## Funcionalidades

- Recibe operaciones mediante argumentos de consola: número1 operador número2
- Ejecuta las operaciones: suma, resta, multiplicación y división
- Guarda cada operación realizada en un archivo `.txt` con nombre basado en la fecha y hora actual
- Muestra cada operación registrada con su fecha y hora alineada a la derecha
- Bucle de operaciones hasta que el usuario decida salir
